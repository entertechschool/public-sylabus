# Ingreso a Code 301

Hay dos formas de entrar a **Code 301: Professional Software Development**.

## Flujo regular

- Manejo básico de computadora y navegador web.
- Conocimientos sólidos de lógica de programación.
- **Code 201: Fundamentals of Software Development** (aprobado).

## Flujo extraordinario: Examen de Admisión

Si ya desarrollas aplicaciones web con JavaScript pero no cursaste Code 201, puedes rendir el examen de admisión y entrar directamente a Code 301.

| Aspecto | Detalle |
|---------|---------|
| **Preguntas** | 25 preguntas técnicas de opción múltiple |
| **Duración** | 120 minutos |
| **Puntaje mínimo** | 80 % (20 de 25 respuestas correctas) |
| **Modalidad** | Examen en línea, con cronómetro |
| **Programación** | Se coordina anticipadamente con el Director Académico de Enter Tech School |

> 📩 El enlace al examen se entrega al momento de rendirlo, en la fecha y hora acordadas.

### Temas evaluados

**Bloque 1: HTML y CSS avanzado**
- Elementos de bloque vs. en línea y su comportamiento en el flujo
- Elementos genéricos vs. semánticos
- Box model: orden de sus componentes y precedencia entre `border-width` y el shorthand `border`
- Posicionamiento: `absolute`, `fixed` y contexto de posicionamiento
- `float` y `clear`
- Selectores y herencia de propiedades (color, fondo)

**Bloque 2: Objetos y prototipos en JavaScript**
- Objetos: notación de punto vs. corchetes, propiedades anidadas y acceso a valores
- Funciones constructoras, `this` y el operador `new`
- Prototipos: `Constructor.prototype` y herencia
- Alcance de variables declaradas dentro de una función constructora
- Funciones como valores: diferencia entre invocar (`fn()`) y referenciar (`fn`)
- Objeto `Date` y métodos como `getTime()`
- Comparación de objetos y evaluación de veracidad

**Bloque 3: DOM, eventos y APIs del navegador**
- Selección y manipulación de elementos del DOM
- Formularios: envío y control desde JavaScript
- `localStorage`: dónde y cómo se almacenan los datos en el navegador

**Bloque 4: Git y flujo de trabajo**
- Recuperar archivos eliminados del repositorio local
- Crear una rama de `hotfix`, corregir y publicar los cambios
- Sincronizar el repositorio local con `main` en GitHub
- Colaboración: repositorios de otras personas, forks y pull requests

### Materiales y recursos

- Computadora con navegador moderno (Chrome recomendado)
- Conexión a internet estable
