# Code 201: Fundamentals of Software Development

**Duración**: 10 semanas (123 horas)  
**Modalidad**: 
   - Clases en vivo online (2 veces por semana, 8:00 PM - 10:30 PM)
   - 20 clases + presentación del Proyecto Integrador al cierre de cada módulo

**Dirigido a**: Personas adultas con conocimientos básicos de desarrollo web (HTML, CSS, lógica con JavaScript).

Este curso consolida tu transición de principiante a desarrollador(a) con fundamentos sólidos. Aprenderás a construir layouts responsivos con Flexbox y Grid, a programar con los tres paradigmas (imperativo, funcional y orientado a objetos), a consumir APIs reales con `fetch` y `async/await`, y a manejar estado persistido en LocalStorage sobre módulos ESM. Cierras con un proyecto integrador individual que construyes con la IA como copiloto dirigido y presentas en un Demo Day.

> 🟡 Requiere conocimientos básicos de HTML, CSS y lógica con JavaScript.

## 🎯 Objetivos de Aprendizaje

Al finalizar este curso, podrás:

- Construir interfaces accesibles con HTML5 semántico y layouts responsivos con Flexbox, CSS Grid y Tailwind CSS.
- Aplicar los tres paradigmas de programación: imperativo, funcional y orientado a objetos con `class`.
- Generar HTML desde datos (render dinámico del DOM) y trabajar con sintaxis moderna ES6+.
- Consumir APIs reales con `fetch`, Promesas y `async/await`, manejando errores y estados de UI (carga / error / vacío).
- Modelar un estado central, aplicar delegación de eventos y persistir datos con JSON y LocalStorage.
- Organizar tu código en módulos ESM (`import` / `export`) y desplegarlo en GitHub Pages.
- Usar la IA en sus tres roles —guía al planificar, copiloto al construir y correctora al auditar— validando siempre su output.
- Justificar decisiones técnicas y explicar tu propio código ante una audiencia técnica.

## Sílabo del Curso

### ▶︎ Módulo 1: Fundamentos de la Web Moderna
Profundizamos en las tecnologías base de la web moderna. Construyes estructuras semánticas y accesibles, dominas los layouts con Flexbox y CSS Grid (incluyendo `grid-template-areas` y responsividad mobile-first), le das identidad visual a tu producto con CSS Variables, validas formularios con HTML nativo y adoptas un flujo Git profesional con ramas y Pull Requests.

1. HTML5 Semántico, Accesibilidad y Formularios
2. CSS Layout con Flexbox
3. CSS Grid Esencial y Flexbox Profundo
4. CSS Moderno (Variables) y Git Workflow

- _Proyecto-integrador_: **Product Landing Page**.

### ▶︎ Módulo 2: Fundamentos de Programación
Recorres los tres paradigmas sobre un mismo proyecto que evoluciona clase a clase. Empiezas con código imperativo y arrays, lo refactorizas con métodos funcionales y arrow functions, resuelves la fragilidad del modelo con objetos y POO (`class`, `constructor`, `this`, encapsulación) y cierras dándole interfaz visual con Tailwind CSS conectada a tu propia lógica.

5. Programación Imperativa y Arrays
6. Programación Funcional y Arrow Functions
7. Objetos y POO con `class`
8. Tailwind CSS e Interfaz del Gestor

- _Proyecto-integrador_: **Gestor de Presupuesto Personal**.

### ▶︎ Módulo 3: JavaScript Moderno y Consumo de APIs
Tu app deja de vivir con datos locales y empieza a traerlos de internet. Aprendes sintaxis ES6+ y el patrón de render dinámico, das tu primer contacto con la asincronía usando `fetch`, Promesas y JSON, reformulas ese código con `async/await` y haces la app robusta con `try/catch/finally`, `throw` y estados de UI claros.

9. JavaScript Moderno y Render Dinámico
10. Datos desde la web: fetch, Promesas y JSON
11. `async/await` y búsqueda en la API
12. Manejo de Errores y Estados (+ documentación con Markdown)

- _Proyecto-integrador_: **Pokédex** (consume la PokeAPI).

### ▶︎ Módulo 4: Estado y Persistencia
Construyes una app real con estado central y patrón `render()`. Manipulas texto con métodos de String y fechas con `Date`, implementas un CRUD completo con delegación de eventos y datos derivados, persistes todo con `JSON.stringify` / `JSON.parse` en `localStorage` y organizas el código en módulos ESM antes de desplegarlo.

13. Modelado de Datos y Manipulación de Texto
14. Interacción y Datos Derivados
15. JSON y LocalStorage
16. Módulos ESM y Cierre del Proyecto

- _Proyecto-integrador_: **Gestor de Plantillas para WhatsApp**.

### ▶︎ Módulo 5: Proyecto Integrador Final
El lab ya no te da el código: trabajas como desarrollador(a) junior con un copiloto de IA. Descompones el MVP en historias de usuario propias, planificas dos sprints, construyes con la IA en modo interactivo (la IA pregunta, tú decides), auditas tu código con un agente de IA y ejecutas tú mismo el plan de pruebas. Publicas en GitHub Pages y defiendes tu trabajo en el Demo Day.

17. Ideación y Planificación con IA
18. Sprint 1 — Construcción del proyecto
19. IA como Corrector + Sprint 2
20. Demo Day

- _Proyecto final_: **Mi Setlist** — busca canciones en el catálogo real de iTunes (iTunes Search API) y las organiza en playlists que persisten en LocalStorage.

> El Proyecto Integrador de M5 integra los aprendizajes de los Módulos 1 al 4 —layout responsivo, lógica algorítmica, consumo de APIs con manejo de errores y estado persistido sobre módulos ESM— e incorpora la IA en tres roles: guía en la planificación, copiloto al construir y correctora al auditar. Regla de oro auditada en el Demo Day: **no entregas código que no puedas explicar**.

## 📝 Cómo se evalúa

### Ponderación de la nota final

| Componente | Descripción | Peso |
|------------|-------------|------|
| **1. Preparación previa y participación en clase** | Lecturas, debates, microprácticas, análisis de código en vivo y asistencia participativa. | **25%** |
| **2. Cumplimiento de laboratorios** | Entrega completa y funcional de los labs individuales, revisión por pares y validación de checkpoints. | **20%** |
| **3. Proyectos Integradores por módulo (M1–M4)** | Implementación de los proyectos intermedios con defensa técnica. | **25%** |

| Criterio | Puntaje |
|----------|---------|
| Historias de usuario implementadas y funcionales | 20 pts |
| Calidad técnica (conceptos del módulo bien aplicados) | 20 pts |
| Presentación de funcionalidades en vivo | 20 pts |
| Argumentación técnica de las decisiones tomadas | 20 pts |
| Desafío: explicar un fragmento del propio código + deploy + README | 20 pts |

### Rúbrica del Proyecto Final — Demo Day (100 puntos)

El proyecto **Mi Setlist** se desarrolla de forma **individual** y se evalúa en el Demo Day (Clase 20):

| Criterio | Qué se evalúa | Puntaje |
|----------|---------------|---------|
| **1. Funcionalidades del MVP** | Los 10 puntos del MVP funcionando: búsqueda en la API con estados de UI, playlists persistidas, estadísticas, orden y robustez ante datos corruptos. | **20 pts** |
| **2. Calidad técnica** | Se respeta el contrato técnico: módulos ESM, estado central + `render()`, CRUD inmutable, `try/catch` en persistencia, delegación de eventos. | **20 pts** |
| **3. Uso responsable de IA + HU propia** | `PROMPTS.md` con prompts contextualizados y decisiones registradas (10) + al menos 1 historia de usuario propia implementada (10). | **20 pts** |
| **4. Presentación en vivo** | Demo clara en ≤10 min sobre la URL pública, flujo completo con recarga en vivo y cierre con la HU propia. | **20 pts** |
| **5. Argumentación técnica + Q&A** | Justifica ≥2 decisiones (≥1 sobre el uso de la IA) y explica el fragmento de código que el instructor elija. | **20 pts** |
