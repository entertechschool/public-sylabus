# Ingreso a Code 201

Hay dos formas de entrar a **Code 201: Fundamentals of Software Development**.

## Flujo regular

- Manejo básico de computadora y navegador web.
- **Code 101: Elementals Software Development** (aprobado).

## Flujo extraordinario: Examen de Admisión

Si ya tienes los fundamentos pero no cursaste Code 101, puedes rendir el examen de admisión y entrar directamente a Code 201.

| Aspecto | Detalle |
|---------|---------|
| **Preguntas** | 25 preguntas técnicas de opción múltiple |
| **Duración** | 120 minutos |
| **Puntaje mínimo** | 80 % (20 de 25 respuestas correctas) |
| **Modalidad** | Examen en línea, con cronómetro |
| **Programación** | Se coordina anticipadamente con el Director Académico de Enter Tech School |

> 📩 El enlace al examen se entrega al momento de rendirlo, en la fecha y hora acordadas. El cronómetro corre desde que lo abres.

### Temas evaluados

**HTML**
- Estructura de un documento: `<!DOCTYPE html>`, `<head>`, `<body>`
- Etiquetas y anatomía de un elemento
- Enlaces y navegación (`<a>`)
- Elementos de bloque y en línea (`<div>`, `<p>`, `<ul>`, `<ol>`, `<h1>`–`<h6>`)

**CSS**
- Sintaxis de una regla y aplicación de propiedades
- Selectores simples (elemento y clase)
- Propiedades de color, fondo y flujo de texto (`float`)

**JavaScript**
- Sintaxis válida y declaración de variables (`let`, `const`)
- Tipos de datos y concatenación / coerción
- Operadores de comparación (`===`) y lógicos (`&&`, `||`)
- Condicionales `if` / `else`
- Declaración e invocación de funciones, y valores de retorno
- DOM básico: seleccionar elementos por clase y cambiar su contenido

**Herramientas**
- CLI: comandos básicos de la terminal (navegación, `tree`, abrir VS Code)
- Git: `clone`, `add` (archivo vs. `.`), `commit`, `push`, `pull` y el flujo local ↔ remoto
- Uso de IA: cómo escribir prompts efectivos (dar ejemplos concretos, descomponer la instrucción en pasos)

### Materiales y recursos

- Laptop con conexión a internet estable
- Navegador Google Chrome actualizado
- Visual Studio Code instalado
