# Code 101 - Flujo acelerado

> En 4 días construyes tu portfolio web desde cero y lo publicas en internet.

Un programa intensivo donde aprendes HTML, CSS y JavaScript construyendo un proyecto real — tu portfolio de desarrollador.

## 📋 Formato del Programa

| Aspecto | Detalle |
|---------|---------|
| **Duración** | 4 sesiones en vivo + 1 día de tarea + entrega |
| **Horario** | Lunes a Jueves, 8:00 - 10:00 PM |
| **Modalidad** | Workshop práctico con guía experta |
| **Proyecto** | Mi Portfolio Dev — sitio web personal publicado |
| **Entrega final** | Día 5 (viernes) vía Canvas |

## 🚀 Lo que vas a construir

Tu propio sitio web profesional de una página con cinco secciones:

- **Hero** — Tu nombre, título profesional y una imagen que te represente
- **About** — Una biografía breve que cuente quién eres y hacia dónde vas
- **Skills** — Cards visuales con las tecnologías y habilidades que dominas
- **Contact** — Un formulario de contacto funcional con validación en tiempo real
- **Footer** — Tus enlaces a redes sociales y copyright

Al terminar, tu portfolio va a estar publicado en tu propia URL: `tunombre.github.io/mi-portfolio-dev`. Un enlace real que puedes compartir con cualquiera.

## 📅 Tu semana, día por día

### Día 1: Tu primera página web

- Configuras tu entorno profesional con VS Code y Live Server
- Escribes la estructura HTML completa de tu portfolio — todas las secciones
- Le das estilo con CSS: colores, tipografía de Google Fonts y espaciado
- Haces tu primer commit en Git y subes tu código a GitHub

Tecnologías: HTML semántico, CSS base, Git

### Día 2: Que se vea profesional en cualquier pantalla

- Organizas el layout con Flexbox: navegación, cards y footer en columnas
- Agregas efectos hover y transiciones suaves a botones y cards
- Implementas media queries para que tu portfolio se adapte a móvil y desktop
- Verificas el resultado en Chrome DevTools simulando diferentes pantallas

Tecnologías: Flexbox, CSS responsive, media queries

### Día 3: Dale vida con JavaScript

- Conectas tu primer archivo JavaScript y pruebas que funciona
- Programas validación de formulario: campos vacíos, formato de email, mensajes de error
- Construyes un menú hamburguesa que se abre y cierra al tocar
- Implementas scroll suave para que la navegación fluya entre secciones

Tecnologías: JavaScript, DOM, eventos, validación

### Día 4: Publicado en internet

- Activas GitHub Pages y verificas que tu URL pública funciona
- Pulís detalles visuales: espaciado, colores, responsive en diferentes pantallas
- Revisas tu proyecto criterio por criterio contra la rúbrica de evaluación
- Haces el commit final y confirmas que el deploy se actualizó correctamente

Tecnologías: GitHub Pages, deploy, debugging

### Día 5: Entrega async

Envías tu proyecto terminado vía Canvas con tu URL de GitHub Pages y el enlace a tu repositorio.

## ❓ Preguntas frecuentes

### ¿Necesito saber programar?

No. El programa empieza desde cero. Lo único que necesitas es tu computadora configurada con las herramientas de la sección anterior y ganas de aprender.

### ¿En qué se diferencia del curso regular de Code 101?

Cubres el mismo nivel de competencias en un formato intensivo. El curso regular dura 12 clases con teoría y práctica separada. El Fast-Track condensa todo en 4 sesiones de workshop donde construyes mientras aprendes.

### ¿Qué pasa si no termino en la sesión?

El Día 5 (viernes) es un día de entrega asincrónica. Puedes seguir trabajando en tu proyecto y hacer push a GitHub hasta la fecha límite. Lo importante es que tu portfolio esté publicado y funcional al momento de entregar.

### ¿Cómo se evalúa?

Con una rúbrica clara de 4 criterios: estructura y Git, diseño responsive, interactividad con JavaScript, y publicación. Cada criterio vale 25 puntos sobre un total de 100. Conoces los criterios desde el Día 1 para que sepas exactamente qué se espera.
